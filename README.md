주인공 이름 : 김남주

기본 정보 : 18살 | 183cm

성격 : 성실함, 다른 이에게 친절함, 훈훈함

고등학교 1학년이었던 나는 무엇에 관심이 있는지 고민하며 성실하게 지냈다. 고민 끝에 농업에 관심이 있다는 것을 깨달았고, 농업을 전문적으로 배우기 위해 도시 외곽에 있는 국제농업전문고등학교로 전학을 가게 된다.
 
<br> 히로인 이름 : 서하린

기본 정보 : 17세 | 158cm | INFP | 강아지상 | 긴 생머리 / 앞머리 있음

성격 : 내향적, 마음에 벽이 있음

서하린은 어릴 때부터 가까운 사람들과 헤어지는 일이 잦았다. 시골에서 태어나 친해진 사람들은 각자의 사정으로 도시로 떠났고, 새로 사귄 친구들과도 비슷한 이별을 반복했다. 이로 인해 하린은 좋아하는 사람과는 결국 헤어지게 된다는 생각을 갖게 됐다.
